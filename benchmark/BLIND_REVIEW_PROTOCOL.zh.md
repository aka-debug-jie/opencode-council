# 论文题 v2 盲评方案

## 目的

这次只评价四份匿名答案本身，不猜它们来自哪个模型或方法。核心问题是：哪份答案更准确地理解三篇论文，找出真正的未决问题，并提出能区分竞争解释的实验。

本次只有一道论文题，因此结果是试点观察，不代表一般性能，也不做显著性结论。

## 评价者会看到什么

- 同一道论文题和三篇论文的来源信息；
- 10 个独立关键点、3 个重大风险和成功标准；
- 4 份随机编号的匿名答案；
- 空白评分表和详细评分指南。

评价者不会看到：

- 答案对应的方法或模型；
- 组别映射；
- token、延迟和调用次数；
- 运行日志、Council 报告或其他答案的生成过程；
- 旧版测试结果和开发阶段的诊断结论。

答案本身可能通过写法暴露线索，所以这里只能称“方法盲评”，不能保证绝对双盲。不要根据风格或自报身份猜组别。

## 评分顺序

1. 先读题目，不看答案，写下你认为最重要的问题。
2. 阅读评分表。如果不认评分项，应先记录异议，不要临时改变分母。
3. 按 README 的随机顺序逐份评价。每份答案独立评分，不做相对排名。
4. 先判断 Task Success，再逐项标记关键点和重大风险。
5. 对每项选择 Hit、Partial 或 Miss，并附答案原文和 1-based 行号。
6. 审计答案中的主要事实性主张，Supported 与 Unsupported 都要列入，避免只挑错误导致分母失真。
7. 对每个新想法分别判断 Novel、Grounded、Testable。只有三项都成立才计入 MNY。
8. 完成所有答案后再做整体复核，不补看组别、成本或旧结果。

## 核心口径

- **Task Success**：答案整体完成任务、没有灾难性遗漏，并给出可执行的区分性实验。
- **KIR／PCIR**：只用 Hit 数除以10个预注册关键点；Partial 单独报告。
- **Catastrophic Miss Rate**：Partial 和 Miss 都保守地计入遗漏分子，同时分别报告数量。
- **Unsupported Claim Rate**：不支持的主张数除以所有实际审计的事实性主张数。没有审计分母时记 NA。
- **MNY**：同时满足 Novel、Grounded、Testable 的候选数除以全部已审计新想法数；没有候选时记 NA。

详细判断例子见 `EVALUATION_GUIDE.zh.md`。

## 推荐评价人数

最好由两位评价者独立完成：

- 第一轮互不查看对方结果；
- 保留两份原始评分表；
- 再针对具体评分项、引文和行号讨论分歧；
- 共识版之外仍保留原始判断，避免只留下修改后的结果。

必须记录 `review_type`：

- `human`：人类评价者独立完成；
- `ai-assisted`：由模型完成或实质参与判断，只能作为暂定评分，不冒充人工评价。

## 揭盲与分析

只有评分表通过完整性检查后才能揭盲。揭盲后再加入方法名称、模型、成本和延迟，生成逐组结果及 Quality–Cost 图。

揭盲前不因为答案残缺而删除样本。空白、乱码、极短或未按要求完成的输出同样是实验结果，应保留并按规则评分。

本次新版和旧版论文测试的权限、评分表及执行协议不同，不能合并成重复样本。新版结果只能单独报告。
